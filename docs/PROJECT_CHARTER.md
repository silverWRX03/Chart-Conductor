# Project charter

**Chart Conductor — Play the Music You Love!** Owner: silverWRX03.

Build a free, open-source Windows application for users' own local music across all genres, intended for personal rhythm-game libraries and initially focused on YARG. This is direction, not current functionality. See the three stages in [ROADMAP.md](../ROADMAP.md).

## Confirmed commitments

- Local processing and local storage; no hosted databases.
- No application accounts/login, telemetry, or song, lyric, stem, project or library uploads.
- Optional model downloads only with informed consent.
- No required paid API, subscription, cloud inference or chat assistant.
- AGPL-3.0-or-later; official releases remain free.

Ordinary files versus a local database is undecided. Application language, UI framework, audio pipeline, models, installers and updates are undecided. GitHub is development infrastructure, never an application backend or route for users' music/libraries.

## Proposed exclusions — owner confirmation required

- No music downloader or streaming-service extraction.
- No DRM circumvention.
- No public song hosting, chart marketplace or sharing service.
- No automatic lyrics scraping.
- No remote-processing or remote-control service.

These proposals require owner confirmation before feature development. They are neither completed controls nor legal guarantees, and official scope adds no restrictions to AGPL recipients. Possession of a file does not imply ownership of copyright. See [legal guidance](LEGAL_AND_LICENSING.md).
